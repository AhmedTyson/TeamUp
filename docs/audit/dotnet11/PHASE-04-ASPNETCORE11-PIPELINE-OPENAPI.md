# Phase 04 Audit — ASP.NET Core 11 Pipeline, OpenAPI 3.2, Caching & Controllers (`TeamUp.Api`)

**Date:** 2026-11-26  
**Scope:** `Program.cs`, `Middleware/*`, `Filters/*`, `Services/*`, and all 20 Controllers in `backend/src/TeamUp.Api/Controllers/`.

---

## 1. Key Findings & Recommendations

| ID | Severity | Location | Finding | Recommendation (Apply Phase 4) |
|---|---|---|---|---|
| API-01 | **P1** | `Program.cs:1-625` | Single 625-line file mixes ForwardedHeaders, CORS, OpenAPI, JWT auth, RateLimiting, Security Headers, inline SQLite DDL patching, Seeding, StaticFiles, and Health endpoints. | Modularize into cohesive extensions under `TeamUp.Api/Extensions/` (`SecurityPipelineExtensions.cs`, `OpenApiAndCachingExtensions.cs`, `DatabaseStartupExtensions.cs`). |
| API-02 | **P1** | `Program.cs:86-104` | Under ASP.NET Core 11 (`Microsoft.AspNetCore.OpenApi 11.0.0` + `Microsoft.OpenApi 3.x`), OpenAPI defaults to **OpenAPI 3.2**. `Program.cs:92` hardcodes `.NET 10`, and `AddDocumentTransformer` registers `Bearer` in `Components.SecuritySchemes` without attaching `OpenApiSecurityRequirement` (`OpenApiSecuritySchemeReference`) to operations. | Verify `Microsoft.OpenApi 3.x` API compilation under `11.0.0`, update description to `.NET 11`, attach `OpenApiSecuritySchemeReference("Bearer", doc)` cleanly, and verify `/openapi/v1.json` returns valid 200 JSON in Dev (and 404 in Prod). |
| API-03 | **P2** | `Program.cs` + `UniversitiesController`, `SkillsController`, `OrganizationsController`, `BadgesController` | No `OutputCache` configured. `GET /api/v1/organizations/public/categories` runs an uncached `GROUP BY` on every request. Note: `SkillsController` and `BadgesController` carry `[Authorize]`, so default `OutputCache` skips requests with an `Authorization` header! | Add `AddOutputCache` + custom `CatalogOutputCachePolicy` (allowing authenticated global read caching on `/skills` and `/badges` while remaining safe against cookies/mutations), tag all 4 endpoints, and call `IOutputCacheStore.EvictByTagAsync` on create/update/delete/restore mutations. |
| API-04 | **P2** | `Program.cs:612-621` | Only ad-hoc `/health` is mapped without `try/catch` around `CanConnectAsync`. Standard Kubernetes/container `/health/live` (liveness, no DB) and `/health/ready` (DB readiness) probes are absent. | Register `AddHealthChecks().AddCheck<AppDbHealthCheck>("database", tags: ["ready"])`, map `/health/live` (`Predicate = _ => false`) and `/health/ready` (`Predicate = r => r.Tags.Contains("ready")`), and preserve `/health` JSON contract (`status`, `database`) with `try/catch` returning 503 on DB error. |
| API-05 | **P2** | `Program.cs:317-325`, `AdminController.cs:116-126` | `AdminController.PreviewEmailTemplate` serves `text/html` at `/api/v1/admin/templates/preview/...`, which does not end with `/report`, so CSP `default-src 'none'` blocks inline styles. | Extend report CSP check in `SecurityPipelineExtensions` to cover `/templates/preview/`. |
| API-06 | **P2** | `Program.cs` (absent) | Response Compression (Brotli/Gzip) is not configured for JSON/CSV/OpenAPI payloads. | Add `AddResponseCompression` carefully (Brotli + Gzip for safe JSON/CSV/HTML/OpenAPI MIME types; keep `EnableForHttps = false` OR explicitly restrict away from auth/credential endpoints to prevent BREACH). |
| API-07 | **P3** | `BaseApiController.cs:8-10` & Controllers (`EventsController.cs:81-82`, `ProjectsController.cs`, `TasksController.cs`, `ImagesController.cs`) | `BaseApiController` `[ProducesResponseType(401)]` omits `typeof(BaseResponse)`; several actions omit `[ProducesForbidden]` / `[ProducesNotFound]` / `CancellationToken ct`; `ImagesController.GetImage` returns bare `NotFound()`. | Standardize response attributes and `CancellationToken ct` parameters on touched endpoints. |
