**Scope:** `AuthService.cs`, `JwtTokenService.cs`, `SecurityStartupValidator.cs`, `SafeUrlValidator.cs`, `ImageFileValidator.cs`, `ImagesController.cs`, `LocalProfilePhotoStorage.cs`, `Options` classes, `Program.cs` security middleware, `STRIDE-THREAT-MODEL.md`.

## 1. Security Findings & Remediation Plan

| ID | Severity | Location | Finding | Remediation (Apply Phase 5) |
|---|---|---|---|---|
| SEC-01 | **P1** | `OrganizationValidators.cs:16-20, 44-48, 134-138` & `SafeUrlValidator.cs:54-60` | `LogoUrl` in Organization create/update/proposal validators uses `IsSafeExternalHttpUrl`, **rejecting** DB-stored `/api/v1/images/{guid}` URLs! Meanwhile, `SafeUrlValidator.IsSafeAssetOrExternalUrl` permits arbitrary `/` relative paths (including `/\evil.com` backslash open-redirect/external vector) and `IsSafeExternalHttpUrl` doesn't strip trailing `.` on `localhost.` (`http://localhost./`). | 1) Switch `OrganizationValidators` `LogoUrl` to `IsSafeAssetOrExternalUrl`. 2) Restrict relative paths in `SafeUrlValidator.IsSafeAssetOrExternalUrl` strictly to exact `/api/v1/images/{guid}` regex (`^/api/v1/images/[0-9a-fA-F]{8}-([0-9a-fA-F]{4}-){3}[0-9a-fA-F]{12}$`) plus `/images/...` and `/logos/...` without `\`, `..`, or control chars. 3) Trim trailing `.` on `uri.IdnHost` before checking `ForbiddenHosts` / `.localhost`. |
| SEC-02 | **P1** | `SecurityStartupValidator.cs:22-31, 80-99`, `appsettings.Development.json:21` | `appsettings.Development.json`'s `"DevelopmentOnlyLocalSigningKeyForTeamUpMustBeOverriddenInProd32B!"` is **not** in `ForbiddenKeyMarkers`! Also Production validation allows empty `Email:SmtpHost` when `Email:Provider == "Smtp"`, and permits `Sqlite` / `UseSqliteFallbackIfOffline=true` outside Development. | Add `"DevelopmentOnlyLocalSigningKey"` and `"MustBeOverriddenInProd"` to `ForbiddenKeyMarkers`; require non-empty `Email:SmtpHost` when `Provider == "Smtp"` outside Dev; forbid `DatabaseProvider=Sqlite` outside Dev (unless explicitly permitted for test/CI). |
| SEC-03 | **P1** | `ImagesController.cs:17-31`, `StudentProfilesController.cs:35-49`, `RateLimitingOptions` | Upload endpoints inherit the 120 req/min global limit, allowing authenticated users to upload up to 240 MB/min of DB BLOBs or disk files. | Add `UploadPermitLimit` (default `10` per window) to `RateLimitingOptions` and apply `[EnableRateLimiting("upload-policy")]` to `ImagesController.UploadImage` and `StudentProfilesController.UploadMyProfilePhoto`. |
| SEC-04 | **P2** | `AuthService.cs:121-137` | `LoginAsync` returns immediately when email is not found or account is locked, skipping PBKDF2 verification and leaking account existence via response-time delta. | Run `hasher.VerifyHashedPassword` against a pre-computed static dummy PBKDF2 hash on both `student is null` and active-lockout paths before throwing `UnauthorizedException`. |
| SEC-05 | **P2** | `DependencyInjection.cs:25-31`, `SecurityOptions.cs`, `AttendanceOptions.cs`, `GamificationOptions.cs`, `NotificationOptions.cs` | All 7 Options classes lack DataAnnotations and `ValidateOnStart()`, allowing negative/zero limits or invalid ports to fail silently or throw mid-request. | Add `[Range]` / validation attributes to options classes and switch DI bindings to `AddOptions<T>().Bind(...).ValidateDataAnnotations().ValidateOnStart()`. |
| SEC-06 | **P2** | `LocalProfilePhotoStorage.cs:46-47`, `ProfileService.cs:372` | Replacing a student's profile photo leaves orphaned `wwwroot/images/people/student-*` files on disk, and `LocalProfilePhotoStorage` lacks canonical `Path.GetFullPath` containment assertion. | Add `Path.GetFullPath` prefix containment check in `LocalProfilePhotoStorage` and clean up old student portrait files after `SaveChangesAsync`. |
| SEC-07 | **P3** | `ImageFileValidator.cs:10-61` | Magic-byte check accepts tiny truncated payloads (e.g., 3-byte `FF D8 FF`) without minimum frame size. | Require minimum valid image payload size (`>= 12` bytes for JPEG/PNG/WebP headers). |
